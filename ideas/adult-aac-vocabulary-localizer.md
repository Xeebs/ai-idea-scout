# Grown Voice: An Adult-Register, Low-Resource-Language Vocabulary Generator for AAC

- **Status**: PROPOSED
- **Date**: 2026-11-13
- **Topic**: Applied AI for underserved domains
- **Source**: research/2026-11-13-applied-ai-for-underserved-domains.md · P5
- **Maturity verdict**: OPEN — `gh search repos` for AAC-adult/accessibility terms returned nothing relevant; web search found only general AAC apps (FreeSpeech, GibTalk, Proloquo2Go, Avaz, This Is My Voice, Flexspeak) that are pediatric-first in design and, where multilingual, cover mainstream languages (Spanish/French/Dutch/Nordic) rather than adult-onset, non-English/low-resource-language cases. No implementation specifically targeting adult, non-English AAC vocabulary surfaced after genuine multi-channel search.
- **Format**: BOTH

## The Gap
A special-needs assistant at a technical college in Brazil posted in r/AssistiveTechnology asking for AAC options for a 35-year-old non-verbal student with epilepsy — explicitly framing this as outside the typical pediatric AAC use case the available tools and research assume. Mainstream AAC apps ship with vocabulary sets built around a child's world (school, playtime, family roles) and, where translated at all, cover high-resource languages. An adult who loses speech later in life (stroke, ALS, epilepsy-related cognitive change, traumatic injury) and speaks a language outside that mainstream set has no vocabulary board that matches either their life stage or their language — they're stuck adapting a kids' app, word by word, by hand.

## The Project
A generation tool for speech-language pathologists, caregivers, and special-needs educators: given a target language, the user's communication/literacy level, and their life context (occupation, living situation, relevant daily activities — work, healthcare, errands, relationships), the tool produces a localized, adult-register AAC vocabulary set — words, short phrases, and symbol-label pairings appropriate to an adult's actual communication needs, translated and culturally adapted rather than machine-translated word-for-word from an English pediatric set. It exports in a format existing AAC apps can import (e.g., Open Board Format, the format CoughDrop and several other AAC tools already support) so the output is immediately usable in a tool the user or clinic already has, rather than requiring a whole new app. A growing, versioned library of validated adult vocabulary sets per language means the next clinician serving an adult Kinyarwanda- or Portuguese-speaking client starts from a reviewed set instead of a blank page.

## Tangible Impact
**Population**: Adults who lose or never develop typical speech later in life and communicate in a language outside AAC's mainstream (English/Spanish/French/Dutch/Nordic) vocabulary coverage — the most-cited global estimate (Beukelman & Light, 2020, via ASHA) puts roughly 97 million people worldwide as potentially benefiting from AAC, and the population this targets is specifically the adult-onset, non-mainstream-language slice of that group that today's pediatric-first, mainstream-language tooling structurally underserves.
**Mechanism**: Today a clinician facing this case either manually re-labels a pediatric vocabulary board word by word (slow, error-prone, and still child-register) or gives up and relies on generic gesture/pointing communication. A generator that produces an adult-register, culturally-adapted starting vocabulary set in the target language turns a multi-week manual adaptation into a reviewable first draft a clinician can produce and refine in one session.
**Measure**: (1) clinician-reported time to produce a usable first-draft vocabulary set, before vs. after; (2) proportion of generated vocabulary items a bilingual SLP or native-speaker reviewer accepts without major revision; (3) number of distinct languages with at least one reviewed, reusable vocabulary set in the shared library over time — the direct measure of whether the gap is actually closing.

## Why Now
This is a single but concrete, specific first-person account — the kind of "I searched and couldn't find one" signal the research-quality rubric treats as strong evidence, even weighed as single-source — landing in the same window as confirmation that no existing AAC product or open project covers this case; LLMs are now capable of the register-aware, culturally-sensitive translation and vocabulary-curation work this requires without needing any new model capability.

## Skill Angle
A Claude Code skill version: given a target language, a brief adult-user communication profile (literacy level, key daily contexts), and optionally an exported vocabulary set from an existing AAC app (to adapt rather than start fresh), the skill generates a localized, adult-register vocabulary set with symbol-label pairings and short phrases, output in Open Board Format so it's directly importable. This is the one-shot generation task a clinician runs per client/language — the project is the persistent, versioned shared library that accumulates and lets future clinicians reuse and improve past language sets instead of regenerating from scratch each time.

## MVP Sketch
Scope to one language (Brazilian Portuguese, directly matching the digest's evidence case) and one life context (the technical-college/workplace setting the original post described). Stack: a structured-intake prompt, a generation step producing Open Board Format output, and a minimal versioned store (even a shared GitHub repo of reviewed OBF files per language to start) so a second clinician can find and reuse the set. The validating experiment: generate a vocabulary set for the original Brazil case (or an anonymized equivalent) and have a native-Portuguese-speaking SLP rate it against what they'd have produced manually.

## Risks & Open Questions
- Data Sources for the MVP are MANUAL (clinician pastes/describes the user's profile and context); a CONNECTED upgrade is plausible via CoughDrop's existing open API/Open Board Format support to pull and push boards directly, but that integration isn't built yet and shouldn't be assumed solved.
- Vocabulary generation for a high-stakes communication tool needs native-speaker clinical review before any set is marked "validated" in the shared library — an unreviewed hallucinated phrase in someone's only communication tool is a serious failure mode, not a cosmetic one.
- Risk this is narrower than it looks: if the real underlying problem is "AAC apps don't let clinicians easily author custom boards at all" rather than specifically "no adult/non-English vocabulary content exists," the fix might be a better authoring UI in existing apps rather than a new generation tool — worth validating with 2-3 practicing SLPs before committing to the build.
- Single-source evidence (one Reddit post) is thinner than the digest's other patterns; this idea should be treated as provisional until a second independent case or a quick SLP-community survey corroborates the demand.
