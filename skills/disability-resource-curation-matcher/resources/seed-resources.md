# Seed Resource Corpus (bundled starter list)

A fixed, bundled starter list of ~35 widely-known, broadly-recommended disability resources,
tools, services, and communities, for use when the person using this skill has not supplied
their own resource list. **This is a small, static snapshot, not a live or exhaustive
database** — it leans toward resources with English-language, US/UK-centric availability and
toward reading/writing, employment, and communication domains, because that is where the
seed research concentrated. It will under-represent other disability types, regions, and
domains until someone extends it. Always disclose this limitation when this corpus is used.

Columns: **Resource** · **Type** · **Disability tags** · **Task domain** · **Fit note** (what
it's broadly known/recommended for — not a fabricated individual testimonial) · **Basis**
(why it's on this list).

## Notes on using this corpus
- Entries above are general, broadly-known resources, not individualized testimonials — a "fit
  note" describes what the resource is commonly known/recommended for, not a specific person's
  guaranteed outcome.
- This file is meant to be edited and grown. Anyone extending it should add real entries with a
  defensible basis (a known org/product, not an invented one) and should note when a fit note is
  thin (tag match only, no real usage evidence) so the matching procedure can flag low confidence.
