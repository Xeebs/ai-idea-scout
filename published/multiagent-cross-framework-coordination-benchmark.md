# Common Ground: A Converged, Cross-Framework Multi-Agent Coordination Benchmark Suite

In the same November 2026 week, two completely unrelated teams launched on Show HN with the same unspoken complaint: nobody can tell them whether their multi-agent system's coordination is actually any good. One built a benchmark inside a Minecraft sandbox. The other built a standalone "Multi Agent Coordination Benchmark" site. Neither had heard of the other. Neither was the first — at least five separate academic efforts had already tried to answer the same question in 2026 alone, and none of them talk to each other either. Everyone keeps re-inventing the same ruler.

## The Gap

Show HN "KradleBench" (multi-agent evals in Minecraft, 9 points, 7 comments) and bespokelabs.ai's "Multi Agent Coordination Benchmark" (16 points, 1 comment) both went up in the same week of November 2026, each a single team's narrow, one-off harness, each unaware of the other. That's not a coincidence worth shrugging off — a wider search turned up at least five distinct academic benchmarks already in play this year (MASBENCH, ALEM, CooperBench, OrchBench, DPBench), plus solo GitHub repos attempting the same thing against AutoGen, CrewAI, and LangGraph independently. Every one of these efforts is measuring a real, shared question — did this coordination architecture actually work? — and every one of them is doing it from scratch, in isolation, with no cross-referencing. That's the gap: not a lack of benchmarks, but a complete absence of convergence among the ones that already exist. Teams building production multi-agent systems on AutoGen, CrewAI, or LangGraph are left choosing between an academic benchmark that wasn't built for their framework, or burning days building a throwaway harness — exactly what both November launches did, independently, in the same week.

## The Project

The fix isn't another one-off benchmark; it's a harness that runs the *same* scenario against a team's actual live stack, whichever of the three major frameworks they're on, and produces a comparable score. The centerpiece is the adapter layer: one scenario, translated through LangGraph's graph invocation API, CrewAI's `Crew.kickoff()`, and AutoGen's `GroupChat` run loop, scored on the same four-metric scorecard — task success, communication overhead, redundant-turn rate, and failure-recovery rate. That's the part no existing effort has, because every existing effort was built for one framework or one narrow domain (Minecraft sandbox cooperation, abstract message-passing tasks) rather than as a portable cross-framework standard.

Underneath the adapters sits a scenario corpus assembled from the already-fragmented sources — MASBENCH, CooperBench, OrchBench, and DPBench task definitions, normalized to one schema rather than invented fresh — because the point isn't to add a sixth incompatible benchmark to the pile, it's to stop the pile from growing. On top of the scorecard sits a public leaderboard for each framework's default out-of-the-box topology, so a team gets a baseline to measure their own custom architecture against before they ship a change. The question this answers — "did switching from mesh to hierarchical actually help coordination?" — currently has no answer without building the kind of bespoke harness both November launches had to build on their own.

## Tangible Impact

**Population**: Engineering teams building production multi-agent systems on AutoGen, CrewAI, or LangGraph who need to validate a coordination-architecture decision (adding a specialist agent, switching topology) before shipping it — the same population already building ad hoc coordination benchmarks from scratch, evidenced by at least seven independent, non-converged efforts in 2026 alone (two same-week Show HN launches plus five academic benchmarks).
**Mechanism**: Today, validating whether an architecture change actually improved coordination means either trusting an academic benchmark not built for your framework, or spending days building a throwaway harness — as both November 2026 launches did independently, in the same week, unaware of each other. A shared, cross-framework suite turns that into a reproducible before/after score run against the team's actual live stack.
**Measure**: (1) Time from "did this architecture change help?" to a comparable before/after coordination score — target: hours via the shared harness vs. the multi-day bespoke-build time each of the two concurrent launches required. (2) Cross-framework consistency — rank-order agreement on a held-out scenario set when the same topology pattern is run through different framework adapters. (3) Number of teams that retire a bespoke in-house coordination harness in favor of the shared suite within a pilot window.

## Try It

A companion skill, `skills/multiagent-cross-framework-coordination-benchmark/` ("Multi-Agent Coordination Benchmark Scenario Advisor"), is already written: it "recommends which multi-agent coordination benchmark scenarios to run before/after an architecture change (new agent, topology switch, agent split), and how to interpret the resulting score delta." It's the one-shot advisory half of the idea — it doesn't execute code or touch a live system, it tells you what to run and how to read it before you commit to building or running the full harness.

To use it: paste the contents of `skills/multiagent-cross-framework-coordination-benchmark/README.md` into any AI chat tool and describe your framework, topology, task domain, and the change you're considering — or drop the whole `skills/multiagent-cross-framework-coordination-benchmark/` folder into `~/.claude/skills/` if you're running Claude Code.

Worth being upfront about: this is a converged standard competing with several narrow, non-converged alternatives, which cuts both ways. Each of the five existing academic benchmarks measures a genuinely different construct — Minecraft-sandbox cooperation isn't the same thing as abstract message-passing — and forcing them into one scoring schema risks flattening exactly what made each of them meaningful. There's also no guarantee the convergence happens here rather than somewhere else: a well-resourced framework vendor (LangGraph or CrewAI) shipping its own first-party coordination benchmark could fragment the space further instead of neutral convergence winning. And the underlying signal for appetite is still thin — two same-week Show HN posts at modest engagement (9 and 16 points) is real evidence of duplication, not yet proof that teams want to converge rather than keep tolerating fragmentation.
